# Swoop

Передача файлов с iPhone на ПК (и обратно) по локальной сети. На Windows работает приложение, которое поднимает веб-сервер. iPhone подключается по QR-коду и открывает веб-приложение в Safari, ничего устанавливать на телефон не нужно.

**Скачать:** [последний релиз](https://github.com/traden0de/swoop/releases/latest) — установщик или портативный exe для Windows 10/11.

Персонаж — существо-почтальон, нарисованное кодом на canvas по технике из `mochi-creature`: суперэллипс, глаза на сфере, твины, пружины. При приёме файла оно превращается в почтовый ящик и «глотает» карточки.

## Запуск для разработки

```bash
npm install
npm run build        # phone.html раздаёт Rust-сервер из dist/, поэтому сборка нужна заранее
npm run tauri dev    # окно ПК + сервер на порту 53917
```

Телефонная часть при правках: `npm run build:watch` в соседнем терминале. В debug-сборке rust-embed читает `dist/` с диска, перезапускать приложение не нужно.

Песочница персонажа со всеми состояниями: `npm run dev`, затем http://localhost:1420/creature.html.

## Сборка установщика

```bash
npm run tauri build
```

Результат — `src-tauri/target/release/bundle/nsis/Swoop_*_x64-setup.exe`. Установщик добавляет правило брандмауэра для частных сетей (`src-tauri/windows/hooks.nsh`).

## Как устроено

| Часть | Где |
|---|---|
| Персонаж (движок, состояния, отрисовка) | `src/creature/` |
| Веб-приложение для iPhone | `src/phone/` (очередь с докачкой — `uploader.svelte.ts`) |
| Окно ПК и мини-виджет | `src/desktop/`, `src/widget/` |
| HTTP-сервер (axum) | `src-tauri/src/server/` |
| Устройства, история, полка, тексты (SQLite) | `src-tauri/src/db.rs` |
| Трей, уведомления, выбор IP | `src-tauri/src/tray.rs`, `notify.rs`, `net.rs` |

**Протокол загрузки:** `POST /api/uploads` → `{id, offset}`, затем `PUT /api/uploads/{id}?offset=N` кусками по 8 МБ. Смещение берётся из длины временного файла `.swoop-incoming/{id}.part`, поэтому после обрыва передача продолжается с точностью до байта. Тот же файл (имя + размер + lastModified) после перезагрузки страницы тоже докачивается.

**Доступ:** QR содержит токен. При сопряжении устройство получает ключ `id.secret`, который передаётся в cookie, в заголовке `x-swoop-key` или в `?k=`. «Новый QR-код» в настройках отключает все устройства.

## Ограничения HTTP в локальной сети

Страница открыта не по HTTPS, поэтому в Safari недоступны Clipboard API (копирование идёт через `execCommand`), Wake Lock и service worker. Экран телефона лучше не блокировать во время передачи; если всё же заблокировали, после разблокировки передача продолжится сама.

## Если телефон не подключается

- Телефон и ПК должны быть в одной сети. Адрес в QR можно выбрать в выпадающем списке под кодом.
- Если Windows считает сеть «Общедоступной», брандмауэр закрывает порт. Swoop покажет предупреждение. Переключите сеть на «Частную» в параметрах Windows.
